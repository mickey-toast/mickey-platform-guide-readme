Toast IQ can rearrange your menu hierarchy without deleting anything. The supported actions are:

- Add an existing menu item to a menu group
- Remove a menu item from a menu group (the item itself is not deleted; it stays available to attach to other groups)
- Attach an existing modifier group to a menu item or menu group
- Remove a modifier group from a menu item or menu group
- Add existing modifiers to a modifier group
- Remove a modifier from a modifier group (the modifier stays available; remove only detaches it from this group)

Menu items can only be added to or removed from menu groups, not directly from a menu. If you ask Toast IQ to put an item on a menu, it will ask which menu group inside that menu to use.

Examples:

- "Add the Caesar Salad to the Lunch Salads group."
- "Remove the Cheese Add-Ons modifier group from the Burger."
- "Add a Vegan Cheese modifier to the Cheese Add-Ons modifier group."
