When pricing your menu entities, you can choose from a variety of pricing strategies. The [Pricing strategies overview](https://doc.toasttab.com/doc/platformguide/adminPricingStrategiesOverview.html) section describes those pricing strategies and tells you how to configure them. Each pricing strategy description begins with a list of the menu entity types to which the pricing strategy can be applied. For example, sequence pricing can be applied to modifier groups while time-specific prices can be applied to menu groups and menu items (including [modifier item references](https://doc.toasttab.com/doc/platformguide/adminPricingModifierOptions.html#adminUnderstandingAModifierOptionsItemReference)).
