Follow the procedure below to access the menu manager.

**To access the menu manager**

1. [Access Toast Web](https://doc.toasttab.com/doc/platformguide/adminAccessToastAdminBackend.html).
2. In the left pane, choose **Menus** to go to the **Menus** page.
3. Choose **Menu management > Menu manager**.
