You can access and view subscriber information using the Guestbook feature. Guestbook displays information and data about your guests. For more information, see this [Toast Support article](https://support.toasttab.com/en/article/Access-Your-Guest-Data-with-the-Guest-Report).

From the **Guestbook** page in Toast Web, you can filter guests by subscription plan.

**To filter and search guests by subscription plan**

1. [Access Toast Web](https://doc.toasttab.com/doc/platformguide/adminAccessToastAdminBackend.html).
2. Go to **Guests > Guestbook** to open the **Guestbook** page.
3. On the **Guestbook** page, select the **More filters** link to open a pane.
4. In the pane, go to the **Subscription plans** section and select the arrow to open a dropdown menu.
5. From the dropdown menu, select the subscription plans to filter by. You can choose an unlimited number of subscription plans.

   ![The Guestbook filter pane in Toast Web.](https://doc.toasttab.com/doc/media/platform-subscriptions-plan-guestbook-filter.png)

   The **Guestbook** page displays all relevant search results.

   ![The Guestbook filter results in Toast Web.](https://doc.toasttab.com/doc/media/platform-subscriptions-plan-guestbook-filter-results.png)
