After you have created your subscription plan, the next step is to customize your subscription plan website. Your subscription plan website is where customers can find and subscribe to your plans.

**To customize your subscription plan website**

1. On the **Create a subscription plan** page, complete the following:

   - Write a short description about your subscription plan.
   - Write a short description for each of the subscription plan benefits.
   - Add or remove a benefit.
   - Preview your website for desktop or mobile.
2. Select the **Save and continue** button to move to the next page.
3. On the next page, add images to your subscription plan website. At least one image is required. Add up to four images.
4. Select the **Save and continue** button to move to the next page.
5. On the next page, add optional subscription plan information, such as:

   - Important dates (for example, pickup windows or dates for special events).
   - Additional notes (for example, age restrictions, special instructions, or allergen notes).
6. Select the **Save and continue** button to move to the next page.
7. On the next page, add frequently asked questions. Add up to three questions. Select the **+ Add FAQ** link to add an FAQ.
8. Select the **Save and continue** button to move to the next page.
9. On the next page, customize the website to match your brand’s style. Select from the following configurations:

   - Select the management group that the changes apply to.
   - Select from available fonts.
   - Select from available colors.
   - Select from available button shapes.
10. Select the **Save and continue** button to move to the next page. This opens the **Review** page where you can review the look of your website before publishing the website.
11. Select the **Finish and launch** button to publish and launch your website. The new page displays the following information:

   - A link to the subscription plan website.
   - A button to send an email about the subscription plan website.
   - Links to social media platforms.
   - Download button for a scannable QR code.
