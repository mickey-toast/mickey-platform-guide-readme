> 📘 Note
>
> Currently, you can only create one new subscription plan at a time. You can create an unlimited number of subscription plans.

You can create a new subscription plan from either the **Subscription plans** page or from the **Subscription plan** page.

> 📘 Note
>
> You can exit the subscription plan setup process at any time. Changes are automatically saved.

**To create a subscription plan from the **Subscription plans** page**

1. [Access Toast Web](https://doc.toasttab.com/doc/platformguide/adminAccessToastAdminBackend.html).
2. Go to **Finance > Payments > Subscription plans** to open the **Subscription plans** page.
3. Select the **Create subscription** button to open the **Toast Subscription plan** page.

**To create a subscription plan from the **Subscription plan** page**

1. [Access Toast Web](https://doc.toasttab.com/doc/platformguide/adminAccessToastAdminBackend.html).
2. Go to **Finance > Payments > Subscription plans** to open the **Subscription plans** page.
3. Select a subscription plan to open the **Subscription plan** page.
4. Select the **Add new** button to open a dropdown menu.
5. Select **Subscription plan** to open the **Toast Subscription plan** page.

### Setting up a subscription plan

You create a new subscription plan on the **Toast Subscription plan** page.

**To set up a subscription plan**

1. On the **Toast Subscription plan** page, complete the following:

   - Enter a name for the subscription plan.
   - Set the price for the subscription plan.
   - Choose if the subscription plan will charge tax.

      - Choose a tax rate. You can choose multiple tax rates.

         > ❗️ Important
         >
         > You are responsible for ensuring that tax rates are configured using accurate state and local tax rates. Please check your local regulations before making any changes or updates to your tax rates.
   - Choose if the subscription plan is a limited-time plan (for example, the plan is only available for a season or until a set date).
2. Select the **Continue** button to move to the next page.
3. On the page, complete the following:

   - List subscription plan benefits.

      > 📘 Note
      >
      > You can add an unlimited number of benefits.
   - Choose if pick up is required for the subscription plan.
   - Choose if you want to collect subscriber addresses for shipping and mailing purposes.
   - Choose if one of benefits is a discount.
4. Select the **Continue** button to move to the next page.
5. On the page, complete the following:

   - Choose the billing frequency.
   - Select the billing date.

      - On a scheduled date. Choose the billing day.
      - On the subscription start date.
   - Choose if there is a one-time joining fee. Set the one-time fee.
6. Select the **Continue** button to move to the next page.
7. On the page, complete the following:

   - Choose how long subscribers have to resolve a failed payment.
   - Choose when subscribers can cancel their plan.

      - Anytime.
      - After a minimum commitment. Set the minimum commitment length.
   - Choose to set a maximum subscriber count.
   - Choose if you will allow subscribers to skip upcoming payments.
8. Select the **Continue** button to move to the next page.
9. On the page, complete the following:

   - Add a guest tag and color.
   - Add a subscriber icon.
   - Add a subscriber short code.
   - Choose the subscriber visibility.

      - Subscriber tags only appear at a specific location.
      - Subscriber tags appear at all your locations.
10. Select the **Continue** button to move to the next page.
11. On the page, complete the following:

   - Assign a revenue center.
   - Assign a sales category.
12. On the page, a preview of your subscription plan is displayed. Confirm the subscription plan details are correct.
13. Select the **Next: Customize website** button to move to the section where you can customize the subscription plan website. For more information, see [Customizing the subscription plan website](https://doc.toasttab.com/doc/platformguide/platformCustomizeSubscription.html).
