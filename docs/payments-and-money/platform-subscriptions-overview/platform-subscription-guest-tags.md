To identify active subscribers on the POS, you add subscriber identification, such as guest tags, colors, icons, and short codes to your subscription plans. When you search for a guest using the **Guest search** screen on the POS, applicable guest tags appear in the guest profile.

> 📘 Note
>
> Pending and inactive subscribers do not appear in the search results.

To view guest tags on the POS, you must add a guest tag and tag color on the **Settings** page in Toast Web or during the setup process. For more information, see [Creating a subscription plan](https://doc.toasttab.com/doc/platformguide/platformCreateSubscription.html).

![The Subscriber identification section on the Subscription plan settings page in Toast Web.](https://doc.toasttab.com/doc/media/platform-subscriptions-plan-guest-tags.png)

**To search and add a guest profile to an order**

1. On the Toast POS home screen, select an order screen.
2. On the order screen, select the overflow menu.
3. From the overflow menu, select the **Customer info** button. This opens the **Guest search** screen.
4. On the **Guest search** screen, you can search for a guest by one of the following options:

   - Phone
   - Name
   - Email
   - House account
5. Search for the guest. Select the search result to display the guest profile. The guest profile pane displays the following:

   - Subscription plan tags
   - Subscriber phone number
   - Subscriber email
   - Guest notes
   - Subscriber address
   - Order history
   - Order summary
   - **Edit customer** button
   - **Select** button

   ![The Guest search screen on a Toast POS device.](https://doc.toasttab.com/doc/media/platform-subscriptions-plan-guest-search-tags.png)
6. To attach a guest profile to an order, select the **Select** button. The guest profile is attached to the order and guest details appear on the order details pane.

   ![Guest profile details shown on the order details pane.](https://doc.toasttab.com/doc/media/platform-subscriptions-plan-guest-subscriber-tags.png)
