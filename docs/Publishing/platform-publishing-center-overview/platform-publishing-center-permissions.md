To access the publishing center, you need the **6. Web Setup > 6.4 Publishing** permission to the location you are logged into.

Additional permissions are required to work with the scheduled publishing feature, which lets you make changes to your Toast configuration that are then saved and published at a later date and time. For more information on scheduled publishing permissions, see [Scheduled publishing permissions](https://doc.toasttab.com/doc/platformguide/platformUnderstandingScheduledPublishingAndChangeSets.html#platformScheduledPublishingPermissions).
