Your guest can choose from a list of allergens when they make a reservation using the Toast Tables booking page.

**To choose allergens when making a reservation**

1. Access the Toast Tables reservation page.
2. Select a time and date for the reservation. This opens the **Book reservation** dialog.
3. In the **Book reservation** dialog, complete the guest information fields.
4. Under the **Allergens** section, select the drop-down menu to show a list of available allergens to choose from.

   ![This image shows the Book reservation dialog on the Toast Tables reservation page.](https://doc.toasttab.com/doc/media/guest-allergies-toast-tables-reservation.png)
5. Select the **Complete booking** button to complete booking the reservation.
