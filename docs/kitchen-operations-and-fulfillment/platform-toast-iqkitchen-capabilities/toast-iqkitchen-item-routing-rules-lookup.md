Toast IQ can list saved item routing rules, which reroute items to different or additional prep stations when a dining option or service area condition matches. Each rule shows its name, condition (dining option or service area), the station the item is originally assigned to, and the station or stations it is sent to when the condition is met. For more information about item routing, see [Advanced item routing](https://doc.toasttab.com/doc/platformguide/adminKitchenDiningRoomReference.html#platformAdvancedItemRoutingReference).

Example queries:

- "What item routing rules do I have?"
- "Which orders get rerouted away from the Grill station?"
- "Show me archived item routing rules."
