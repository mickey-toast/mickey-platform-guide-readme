Follow the instructions below to create a version of a configuration entity.

> 📘 Note
>
> For information on what a version is, see [Versions](https://doc.toasttab.com/doc/platformguide/versions.html).

**To create a version of a configuration entity**

1. [Log in to Toast Web](https://doc.toasttab.com/doc/platformguide/adminAccessToastAdminBackend.html).
2. View the details page for the configuration entity you want to version.
3. Select the **New Version** button next to the Number field.

   ![](https://doc.toasttab.com/doc/media/new_version_button.PNG)

   You see the **New Version** window.

   ![](https://doc.toasttab.com/doc/media/new_version_window.PNG)
4. Select a target and an owner for the version. Note that you must set an owner that is at the same point in the restaurant group hierarchy as the target or above. For more information on targets, see [Targets](https://doc.toasttab.com/doc/platformguide/targets.html). For more information on owners, see [Owners and permissions](https://doc.toasttab.com/doc/platformguide/ownersAndPermissions.html).
5. Select **Submit**.
