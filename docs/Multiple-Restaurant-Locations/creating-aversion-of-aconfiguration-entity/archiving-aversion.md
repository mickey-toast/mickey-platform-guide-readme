When you no longer need a version, you can archive it. Archiving a version removes it from Toast Web.

**To archive a version of a configuration entity**

1. [Log in to Toast Web](https://doc.toasttab.com/doc/platformguide/adminAccessToastAdminBackend.html).
2. View the details page for the configuration entity you want to archive.
3. Select the **Actions** button at the top right of the page and select **Archive** from the menu:

   ![](https://doc.toasttab.com/doc/media/actions_button.PNG)
4. Select **OK** to confirm that you want to archive the version.
