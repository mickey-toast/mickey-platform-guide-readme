To remove a discount from the available discounts, you archive the discount.

Archived discounts do not display on the **Discounts** list. They do not display on a Toast POS device and are not applied automatically.

To archive a discount, select the **...** icon for the discount, then select **Archive**.

To display the list of archived discounts, on the **Discounts** list, select **Show Archived**. To return to the **Discounts** list, select **Back to Discounts**.

![List of archived discounts.](https://doc.toasttab.com/doc/media/discounts-archived.png)

From the archived discounts list, to restore a discount to the **Discounts** list, select the **...** icon for the discount, then select **Unarchive**.

After you archive or restore a discount, select **Save** to save the change, then [publish the changes](https://doc.toasttab.com/doc/platformguide/platformPublishingOverview.html).
