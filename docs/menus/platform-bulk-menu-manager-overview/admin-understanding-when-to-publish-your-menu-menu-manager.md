After completing one or more menu configuration changes, you can save them and immediately publish them or, for changes made on the **Items**, **Modifiers**, and **Price levels** views, you can schedule them for future publishing. Toast support recommends that you publish your menu configuration changes when you are ready for them to be seen by your guests (on Toast Online Ordering, Toast Takeout, Toast Order and Pay, or Toast Kiosk) and employees (on the Toast POS app). For more information on publishing changes from menu manager, see [Publishing menu manager changes](https://doc.toasttab.com/doc/platformguide/platformPublishingMenuManagerChanges.html).
