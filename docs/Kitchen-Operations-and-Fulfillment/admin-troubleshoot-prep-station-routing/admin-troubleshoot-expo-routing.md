For efficient kitchen management, the [expediter](https://doc.toasttab.com/doc/platformguide/adminUsingExpo.html) must receive all of the orders for supervised prep stations.

To review and update which prep station orders the expediter receives you must have the **Web Setup > Kitchen / Dining Room Setup** access permission. Then, follow these steps.

1. [Access Toast Web](https://doc.toasttab.com/doc/platformguide/adminAccessToastAdminBackend.html).
2. Choose **Kitchen > Kitchen stations > Prep stations**. An interactive grid with rows for each prep station appears.
3. Review the **Send to** setting for each prep station.
4. To change whether orders for a prep station go to the prep station, expediter, or both, select the appropriate option from the dropdown menu in the **Send to** column.
5. Save and publish your changes.
