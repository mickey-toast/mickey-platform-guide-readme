Toast IQ can create a new assembly line that defines the sequence of prep stations a ticket flows through. Editable fields include:

- Name
- Ordered list of prep stations on the line

> ❗️ Important
>
> An assembly line can only include prep stations that already exist at the restaurant. Create or rename any prep stations you need first, then ask Toast IQ to build the assembly line.

Example queries:

- "Create a Hot Line assembly line with Grill, Saute, and Plating in that order."
