Toast IQ can update an existing item routing rule. Editable fields include:

- Name
- Condition: switch between a dining option and a service area, or change which dining option or service area triggers the rule
- The prep station you reroute from
- The prep station or stations you reroute to
- Archive status

> ❗️ Important
>
> Toast IQ updates only the fields you ask about. If the value is already what you requested, Toast IQ will tell you no change is needed. Condition changes still require exactly one of dining option or service area on the result.

Example queries:

- "Rename the Patio Drinks item routing rule to Patio Beverages."
- "Change the takeout item routing rule to send to the Pickup station instead of Expo."
- "Archive the Brunch item routing rule."
