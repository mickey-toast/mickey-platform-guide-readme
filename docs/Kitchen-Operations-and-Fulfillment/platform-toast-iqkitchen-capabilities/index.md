Toast IQ is the conversational assistant in Toast Web. It can answer questions about your kitchen configuration and make a focused set of changes on your behalf using natural language. This topic describes what you can ask Toast IQ to do for kitchen operations, exactly which fields it can change on each entity, and which settings must still be changed manually.

Toast IQ understands the kitchen entities that drive order fulfillment: prep stations, assembly lines, courses, meal pacing, KDS devices, and item routing rules. For more information about how these entities fit together, see [Kitchen](https://doc.toasttab.com/doc/platformguide/adminKitchenDiningRoomReference.html#adminKitchenSetupReference) and the related kitchen configuration topics.
