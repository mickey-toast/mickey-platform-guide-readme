Toast IQ can create a new prep station at the current restaurant. Editable fields include:

- Name

> ❗️ Important
>
> When you create a prep station with Toast IQ, only the name is set. Whether tickets are always printed and expediter routing are configured separately. To configure these settings using Toast IQ, see [Updating a prep station](doc:toast-iqkitchen-prep-stations-update). For printer assignment, and for information about how to configure these settings manually, see [Adding a prep station](https://doc.toasttab.com/doc/platformguide/adminAddPrepStation.html).

Example queries:

- "Create a prep station called Cold Line."
- "Add a new Pastry prep station."
