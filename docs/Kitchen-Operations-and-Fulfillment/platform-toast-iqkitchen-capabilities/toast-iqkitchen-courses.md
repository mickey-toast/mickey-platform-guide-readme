Toast IQ can list kitchen courses, including their name, sort order, and target restaurant set, across one or many locations. It can also look up the course firing configuration, including how meals are paced and fired in the kitchen. For more information, see [Courses](https://doc.toasttab.com/doc/platformguide/adminKitchenDiningRoomReference.html#configCoursesSection) and [Meal Pacing](https://doc.toasttab.com/doc/platformguide/adminKitchenDiningRoomReference.html#adminCoursePacingReference).

Example queries:

- "List all the courses configured at this restaurant."
- "What courses do I have across all my locations?"
- "How is course firing configured?"
- "What's my meal pacing configuration?"

Toast IQ does not create or edit courses, course firing settings, or meal pacing configuration through conversation. Make those changes manually in Toast Web.
