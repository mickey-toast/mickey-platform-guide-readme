Toast IQ can update an existing prep station's settings. Editable fields include:

- Name
- Always print ticket (yes/no)
- Expediter routing: **Prep station only**, **Prep station and expediter**, or **Send to expediter only**

Toast IQ only updates the fields you specify. It does not make other unrelated changes. If the requested change is already in effect, Toast IQ will tell you no change is needed. Updates apply only to a station at your current session location; Toast IQ will tell you if the named station exists only at other locations and ask whether to switch.

Example queries:

- "Rename Beverages to Soda Bar."
- "Change the Grill prep station to send to expediter only."
- "Stop always printing tickets at the Cold Line station."
